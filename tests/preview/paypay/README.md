# PayPay部品の表示確認

通常の開発サーバーを停止してから、プロジェクトのルートで実行します。

```bash
npm run dev:paypay
```

表示されたURLをブラウザで開きます。Firebaseには接続せず、保存先はメモリ内です。ページを更新すると検証データが初期状態に戻ります。外部リンクを開く操作も画面内の表示に置き換えます。

- 「請求する」→「自分のリンクを未登録にする」で、入力欄と保存を確認。
- 「自分のリンクを登録済みにする」→「リンクを再登録する」で、入力・保存・取消を確認。
- 入力例は `https://qr.paypay.ne.jp/p/preview-long-example-link`。保存中は操作できない表示になり、完了後は登録済みの表示へ戻ります。
- 「支払う」で登録済み・未登録の相手を切り替え、取得失敗や遅延時の表示を確認。
- 「レシート詳細を開く」で同じ部品がレシート内でも表示されます。
- ブラウザ幅320px・390px・PC幅で確認します。実スマホと、通常アプリの支払い詳細・まとめ精算への接続確認は別に行います。

編集対象は実際の `src/components/PayPayAction.vue` です。この確認画面用のファイルを編集しても、アプリの見た目は変わりません。通常のアプリを開く場合は停止して `npm run dev` を実行してください。
