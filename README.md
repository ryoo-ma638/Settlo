# Settlo（セトロ）

> レシートを撮るだけ。グループの「割り勘」と「精算」を、もう迷わせない。

**Settlo** は、旅行・飲み会・イベントなど、グループでの支払いを
**記録 → 自動精算 → 支払い** までシームレスにこなせる割り勘アプリです。

🔗 **公開URL： https://settlo-app.web.app**

## ✨ 主な機能

- 🧾 **レシートAI読み取り** — 撮影するだけで店名・金額・消費税・品目を自動入力（Gemini）。**1回に5枚までまとめて読み取り**、1枚ずつ確認して不要な分は外せる
- 🍽️ **柔軟な割り勘** — 「全員で均等」「金額を指定」「商品ごとに支払う人を選ぶ」の3方式
- 🏷️ **支払いジャンル** — 食事・カフェ・コンビニ・交通など、支払いごとにアイコンで分類
- 🧮 **まとめて精算（2種類）** — ①イベントの参加者全員の貸し借りを一度に相殺 ②相手ごとに全イベントをまたいで相殺。どちらも**送金の回数が最小**になる組み合わせを選び、できるだけ100円単位で割り切れる金額にする
- ➗ **イベントを作らずに1件だけ割り勘** — いつものメンバーで軽く出し合うとき用。記録する前に「誰が誰へいくら」を確認できる
- 👥 **イベント & 参加者管理** — 招待コードで参加、参加者やイベント内容の編集も可能
- 🤝 **フレンド & 取引履歴** — 申請・承認、相手との過去の取引を確認できる
- 🔔 **通知** — 承認リクエスト・催促・拒否をアプリ内＋プッシュで通知（一言メッセージも添えられる）
- 💬 **件ごとのチャット** — 「〇〇の支払いの件」単位で相談。既読・未読バッジつき、解決したら自動で片付く
- 🤖 **AIと返信を考える** — 会話を読んで返信案を3つ提案（Gemini）。「PayPayが使える」「いつまでに払う」などの条件に沿わせられる。**AIには名前を渡さず「参加者1」に置き換えて送る**
- 🔁 **差し戻し（要確認）** — 相手が「受け取っていない」と戻した分を、普通の未払いと分けて表示。次の精算に自動で混ぜない
- ♻️ **元に戻す** — 削除した立て替えや非表示にしたイベントを戻せる（7日で自動削除）
- ✅ **承認待ちビュー** — 自分が承認する分・相手待ち・承認/拒否の履歴をひと目で。催促中は最上部に強調
- 📊 **精算の進捗表示** — イベントごとに「未精算の残り」と完了率を可視化
- 🎓 **初めての方への案内** — お試しで入ると、押すボタンを1つずつ光らせて7つの機能を案内。3〜5分でひと通り触れる
- 🕹️ **ゲストデモ** — 登録なしでデモデータつきのお試し体験（ログイン画面から）
- 📱 **PWA対応** — ホーム画面に追加して単体アプリとして起動

## 🚀 セットアップ（ローカル開発）

```sh
# 1. 依存関係をインストール
npm install

# 2. プロジェクト直下に .env.local を作成し、Firebase の設定（VITE_FIREBASE_*）を記述
#    ※ ファイル名が .env.dev だと Vite が読み込まないので注意（.env.local を使う）

# 3. 開発サーバーを起動
npm run dev          # → http://localhost:5173

# 本番ビルド
npm run build
```

```sh
# テスト（変更を入れる前に毎回通す）
npm test
```

## 🧭 設計で大事にしたこと

- **金額の正データは取引（`transactions`）1本。** 画面に出す数字はそこからしか作らない（同じ金額を2か所で持つとずれるため）
- **現金は相手の承認で完了。** 片方が「払った」と言うだけでは終わらない。承認・拒否の履歴は消さない
- **お金を確定させる処理はサーバー側だけ。** まとめて精算の記録はクライアントから書けず、精算に予約された取引は編集も削除もできない
- **計算は画面から切り離した純粋な関数に。** そこにテストを書き、金額と状態遷移を固定している

```
src/
├─ views/        # 画面（Home / Event / Money / Friend / Login など）
├─ components/   # UI部品（モーダル・カード・アイコン）

functions/        # Cloud Functions（レシート読み取り・イベント全体の精算・通知・相談）
tests/            # 55ファイル・414件
```
